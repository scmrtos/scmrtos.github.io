Welcome to scmRTOS!
=======

scmRTOS is tiny Real-Time Preemptive Operating System intended for use with Single-Chip Microcontrollers. 
scmRTOS is capable to run on tiny uCs with as small amount of RAM as 512 bytes. 
The RTOS is written on C++ and supports various platforms.
